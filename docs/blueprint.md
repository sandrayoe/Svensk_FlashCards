# **App Name**: Svenska Flash

## Core Features:

- Word Generation: Generates 5 random Swedish words daily using an AI tool. The AI tool is responsible for filtering out rare or difficult-to-understand words, ensuring that only the most common and useful words are included. It also avoids nouns without definite articles to avoid confusing the user.
- Translation: Provides accurate English translations for each Swedish word.
- Pronunciation: Offers text-to-speech functionality for correct Swedish pronunciation.
- Daily Delivery: Delivers a fresh set of words every day to encourage consistent learning.
- Regenerate Words: Allows users to generate a new set of 5 Swedish words for the day if they are not satisfied with the initial set. This uses the AI tool.

## Style Guidelines:

- Primary color: Swedish Blue (#0058A3) to reflect the Swedish flag and create a sense of national identity.
- Secondary color: Swedish Yellow (#FFDA63) as a complementary color for highlights and accents.
- Background color: Very light blue (#F0F8FF) for a clean and calming learning environment.
- Headline font: 'Playfair Display', serif, for titles and important words; body font: 'PT Sans', sans-serif, for descriptions and translations.
- Use simple, clear icons for the text-to-speech and settings functions.
- Clean, minimalist design to keep the focus on the words and their translations. Ensure responsive design for use on different devices.
- Gentle animations on word reveal and transition for a smooth, engaging experience.
